# raven-march-training

## Verification runs

This repository is used by embry0 as a scratch target for live pipeline verification runs. Branches prefixed `embry0/` are created by those runs and are disposable — they may be deleted at any time without notice. Pull requests opened from `embry0/` branches are verification artifacts and are not intended to be reviewed or merged as course work. Anything outside that prefix is regular repository content and is unaffected.
